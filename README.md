# Pimpin Launcher downloads

Grab the newest version from [Releases](https://github.com/Nos-and-Stealzers/pimpin-launcher-releases/releases/latest).

- **Windows 10/11:** `PimpinLauncher-Setup-*.exe` (installs and updates itself) or `PimpinLauncher-Portable-*.exe` (no install).
  The app isn't code-signed yet, so SmartScreen may warn you: click **More info → Run anyway**.
- **Linux:** the `.AppImage` (`chmod +x`, then run it; updates itself) or the `.deb`.

This repo only holds the installers. Installed launchers check it for updates.
